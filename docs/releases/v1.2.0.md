A feature release: sleep playlists, playlist editing on iOS, up to three updates a day in your own timezone, a new logo, and a round of security and reliability fixes.

## Highlights

- **Sleep playlists** (#332, #333). A new playlist kind that plays only episodes you've already finished, to fall asleep to. Every episode a sleep build writes is remembered, so a replayed serial episode doesn't come back into your normal playlists as unplayed. Available on the web and on iOS.
- **Edit playlists on iOS** (#330). Create, edit and delete playlists, reorder their podcasts, and set each podcast's episode limit, take-from rule and sequential flag, with a preview of the next rebuild. Until now this was web-only.
- **Up to three updates a day** (#285). The library sync and playlist update can run at up to three times a day, so an episode released mid-morning reaches your playlist the same day. One run a day is still the default.
- **Update times in your timezone** (#287). The schedule now runs in a configurable `TIMEZONE` and follows daylight saving, and the web app labels the times with that zone. Before, a UK user who picked 06:00 got a 07:00 run all summer.
- **Serials in the right order, again** (#329). Shows that Spotify lists oldest-first, which is typical of serials, could have two same-day parts swapped or part 1 skipped. Each show's listing direction is now detected before its episodes are ordered.
- **Security hardening** (#293). An optional `OWNER_SPOTIFY_ID` locks sign-in to your account, including the very first one. Session IDs are stored hashed, so a copy of the database no longer signs anyone in. Proxy and debug defaults are safer.
- **Reliability** (#290, #291, #292, #294). Playlist builds ride out Spotify hiccups better. Token refresh and re-auth bugs are fixed. Long Spotify runs no longer hit "database is locked". API input is validated, closing two write races.
- **Web app fixes** (#289). Manual runs no longer show a 504 for rebuilds that succeed, and a deploy no longer leaves a blank page from a cached `index.html`.
- **New logo** (#334). A microphone on Spotify green, now used for the iOS app icon, the web app's favicon, header and login page, and the website.

## Upgrading

- **Migrations run on their own** at container start: `020_hash_session_ids` hashes existing sessions in place, so nobody is signed out, and `021_sleep_playlists` adds the sleep playlist tables. Rolling back to 1.1 afterwards means signing in again.
- **New optional settings**, none required:
  - `TIMEZONE`, an IANA name such as `Europe/London`. It defaults to `UTC`, which keeps the run times you already have. If you set it, check your update times in Settings, because they are now read in that zone.
  - `OWNER_SPOTIFY_ID`, your Spotify user ID. Set it to stop anyone else claiming a fresh install.
- Otherwise, pull the new images and restart (`IMAGE_TAG=1.2.0`).
