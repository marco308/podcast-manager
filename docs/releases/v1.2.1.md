A security patch: the backend image no longer trusts the compromised eMudhra emSign root CA.

## Highlights

- **Untrusted emSign CA removed.** Private keys for eight eMudhra intermediates were recovered, so anyone could forge a certificate chaining to *emSign ECC Root CA - G3* and impersonate the hosts the backend talks to, Spotify's API and accounts service included. The backend now requires `certifi` 2026.10.19 or later, which drops that root, and the image is rebuilt on a current `python:3.14-slim`, whose system store and bundled pip (26.2.2) drop it too. See the [Python advisory](https://discuss.python.org/t/information-for-python-users-regarding-emudhra-emsign-ca-certificate-security-incident/109576).
- **Dependency updates** since 1.2.0 (Dependabot): minor and patch bumps of FastAPI, SQLAlchemy, Pydantic, pydantic-settings, python-dotenv and the frontend's npm packages.

## Upgrading

- No migrations and no config changes. Pull the new images and restart (`IMAGE_TAG=1.2.1`).
- If you build the image yourself, build with `--pull` so you get the fixed base image.
