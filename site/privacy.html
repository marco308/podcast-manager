Privacy Policy

Last updated 23 September 2026

Podcast Manager is a self-hosted app. The iOS app talks only to a Podcast Manager server that you (or someone you trust) run. The developer of the app does not operate that server and never receives your data.

What the iOS app stores on your device

  • The server address you type on the sign-in screen.
  • A session token for that server, kept in the iOS Keychain. It is never synced to iCloud and is deleted when you sign out.

What the iOS app sends, and where

  • Everything it does goes to the server address you entered, over HTTPS.
  • Signing in opens Spotify's own sign-in page in the system browser. Spotify's privacy policy covers that step.
  • Podcast artwork is loaded from the image links Spotify provides.

The app contains no analytics, advertising or crash-reporting code and does not track you.

What the server stores

The server keeps what it needs to manage your playlists: your Spotify display name, email address and user ID, encrypted Spotify access tokens, the podcasts you follow, and the playlists you set up. It uses them only to talk to Spotify on your behalf. That data lives on the server you run, under your control. To remove it, delete the server's database.

Notifications

If you allow notifications, the app shows a local notification when a sync or playlist run you started finishes while the app is in the background. No push service is involved.

Children

The app is not aimed at children and collects nothing beyond what is described above.

Changes and contact

Any change to this policy will be published on this page. Questions can go to the project's GitHub issues.
