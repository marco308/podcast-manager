# Brand

The Podcast Manager mark: a microphone on a Spotify-green gradient.

| File | Use |
|---|---|
| `logo.svg` | Master artwork, square. Source for the iOS app icon (iOS applies its own corner mask). |
| `logo-rounded.svg` | The same art with icon-style rounded corners, for places that show it unmasked. Copied to `frontend/public/icon.svg`. |
| `logo-1024.png` | 1024×1024 raster of `logo.svg`. |

The app icon (`ios/.../AppIcon.appiconset/AppIcon.png`), the iOS `Logo` image set, `frontend/public/apple-touch-icon.png` and the inline marks in `site/index.html` are all generated from these. If you change the artwork, regenerate them.

Colours: gradient `#22E06B` → `#0FA34A`, ink `#0B0F17`, grille `#1ED760`.
